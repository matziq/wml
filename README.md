# Ward Mission Leader resources

Mobile-friendly ward mission resources published with GitHub Pages at
**https://wardmission.org**.

## Missionary Style activity

- Quiz: `https://wardmission.org/personality.html`
- Spark tips: `https://wardmission.org/personality-spark.html`
- Bridge tips: `https://wardmission.org/personality-bridge.html`
- Beacon tips: `https://wardmission.org/personality-beacon.html`
- Seed tips: `https://wardmission.org/personality-seed.html`

The eight-question quiz is strengths-based rather than clinical. It stores no
responses and sorts participants into four groups for an in-person teaching
activity.

## Domain notes

This repository serves `wardmission.org` via the `CNAME` file. The content
previously lived under `memconfigmgr.org`. Those old paths still redirect
here, so printed handouts and existing QR codes remain valid.
