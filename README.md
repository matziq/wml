# Love, Share, Invite

Mobile-friendly missionary activity resources published with GitHub Pages.

## Missionary Style activity

- Quiz: `https://matziq.github.io/wml/personality.html`
- Spark tips: `https://matziq.github.io/wml/personality-spark.html`
- Bridge tips: `https://matziq.github.io/wml/personality-bridge.html`
- Beacon tips: `https://matziq.github.io/wml/personality-beacon.html`
- Seed tips: `https://matziq.github.io/wml/personality-seed.html`

The eight-question quiz is strengths-based rather than clinical. It stores no
responses and sorts participants into four groups for an in-person teaching
activity.
